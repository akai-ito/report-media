# report-media

Screenshots for [Ito](https://github.com/akai-ito/ito-core)'s reports.

When you ask Ari to pass feedback on to Ito's developers, Ari drafts the report in the chat and
shows you the screenshots it would attach. Only when you choose *File it* does Reports store them
here and show them in the issue on [akai-ito/ito-core](https://github.com/akai-ito/ito-core/issues).

Each file is named by its content and filed by month. Nothing else lives here.
